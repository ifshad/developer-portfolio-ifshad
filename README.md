## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn

### Installation

1. Clone the repository:
   `https://github.com/ifshad/developer-portfolio-ifshad.git`
2. Navigate to the project directory:
   `cd developer-portfolio-ifshad`
3. Install dependencies:
   `npm install`
4. Run the development server:
   `npm run dev`
5. Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.

## 🎨 Customization

To customize the content, update the relevant components in the `components/` directory and modify the pages in the `pages/` directory.
